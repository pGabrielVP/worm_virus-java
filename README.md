# worm_virus-java

O código infecta apenas arquivos dentro de uma pasta-alvo, definida na variável pAlvo.

## Executando

**Windows**

```console
  java .\Virus.java $(cat .\Virus.java -Raw)
```

**Linux**

```console
  java Virus.java "$(cat < Virus.java)"
```
